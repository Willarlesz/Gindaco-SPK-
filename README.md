# SPK Pengadaan Bahan Baku Gindaco (Exponential Smoothing, BOM & CSV Import)
Project Skripsi Teknik Informatika - Wildan Ari Leksono

## Cara Install di XAMPP (Laptop):
1. Copy folder `gindaco_spk` ke dalam direktori `htdocs` XAMPP (`C:\xampp\htdocs\gindaco_spk`).
2. Nyalakan Apache dan MySQL di XAMPP Control Panel.
3. Buka browser dan akses `http://localhost/phpmyadmin`.
4. Buat database baru bernama `db_spk_gindaco`, lalu import file `database.sql`.
5. Akses website melalui `http://localhost/gindaco_spk/index.php`.
